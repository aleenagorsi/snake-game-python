🐍 Snake Game (Python + Pygame)

A classic Snake Game built from scratch using Python and Pygame. The player controls a snake that grows longer each time it eats food, while avoiding collisions with the walls or itself.

Features
Smooth grid-based snake movement using arrow keys
Randomly spawning food
Real-time score tracking
Collision detection (walls and self-collision)
Game Over screen displaying final score
Tech Stack
Language: Python
Library: Pygame (pygame-ce)
How to Run
Clone this repository
bash
git clone https://github.com/aleenagorsi/snake-game-python.git
cd snake-game-python
Install dependencies
bash
pip install pygame-ce
Run the game
bash
python snake_game.py
Controls
Arrow Keys — control the snake's direction
Eat the red food block to grow and increase your score
Avoid hitting the walls or your own body!
